# Логи игры

Обычные диагностические сообщения игровых скриптов проходят через `Failsafe.Debugging.GameplayLog.Trace`. Без символа `FAILSAFE_VERBOSE_LOGS` компилятор удаляет вызов вместе с вычислением аргументов — и в Unity Editor, и в Development/Release. Для временной диагностики символ можно включить в Scripting Define Symbols и затем убрать перед замером производительности.

`RunSaveLog.Info` также требует `FAILSAFE_VERBOSE_LOGS`. `EffectLog.Info` сохраняет отдельный существующий флаг `EFFECT_VERBOSE`; наличие `UNITY_EDITOR` больше не включает его автоматически.

`Debug.LogWarning`, `Debug.LogError`, исключения, отчёты Performance и явно запрошенные диагностические команды сохраняются. `Debug.unityLogger.logEnabled` не отключается. Предупреждения Unity о нескольких AudioListener/EventSystem необходимо исправлять в конфигурации сцены, а не скрывать.

Не передавать обязательные игровые действия в аргументы Trace/Info: в обычной конфигурации эти аргументы не выполняются. Использовать Trace для частой диагностики, Warning/Error — для проблем, требующих исправления. Не писать сообщение каждый Update/FixedUpdate даже для ошибок: устранять причину либо сообщать при изменении состояния.
