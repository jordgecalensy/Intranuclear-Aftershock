# Привязка инвентаря к панелям Руви

Компонент `InventoryPanelBinding` совмещает существующий UI с прямоугольником,
заданным тремя точками. Работает в редакторе и после анимации в игре.
Создайте два экземпляра: на `InventoryPanelAnchor` и `QuickBarPanelAnchor`.
Объекты с компонентами должны оставаться активными, даже если UI скрыт.

## Основной инвентарь

- Bottom Left / Bottom Right / Top Left: три точки основной панели.
- Target Root: `GridRoot`, содержащий Canvas, сетку, подсветки и `InventoryItemsRoot`.
- Reference Rect: прямоугольник рабочей сетки — используйте объект из поля
  Grid Cells Root существующего `InventoryRobotPresentationLayout3D`.
- Additional Roots: пусто, если `InventoryItemsRoot` уже внутри Target Root.

## Квикбар на открытом роботе

- Три точки: с отдельной панели квикбара.
- Target Root: `QuickBarCanvas`.
- Reference Rect: общий прямоугольник всех открытых слотов — объект из поля
  Quick Slots Root существующего `InventoryRobotPresentationLayout3D`.
- Additional Roots: `QuickSlotItemsRoot`, если он расположен отдельно от Canvas.

Не назначайте общую `InventoryScreen` целью обоих компонентов: каждый компонент
должен двигать только свою панель. Не назначайте сюда отдельный экранный квикбар
для закрытого инвентаря. Существующее переключение открытой и закрытой раскладки
остаётся в `InventoryQuickBarPresenter3D`.

## Точки и настройка

Смотрите на панель со стороны игрока. Точки отмечают нижний левый, нижний правый
и верхний левый углы. Точки следуют за костью, но не должны быть дочерними
объектами перемещаемого UI. Угол между сторонами должен быть прямым.

Сначала выключите Preview In Editor, заполните ссылки, затем нажмите
«Совместить с панелью». Кнопка поддерживает Undo. Включите Preview In Editor,
чтобы UI автоматически следовал за изменением точек. Это изменяет Transform
целевых объектов: сохраните сцену/префаб, если хотите сохранить настройку.
Отключение preview прекращает обновления, но не восстанавливает старую позу.

Surface Offset — отступ в мировых единицах. Положительное направление показано
жёлтой линией; отрицательное значение переносит UI на другую сторону поверхности.
Padding — отступ от границ панели в мировых единицах.

Пропорции сохраняются: прямоугольник центрируется и вписывается целиком, без
растягивания ячеек. При разном соотношении сторон остаются поля. Компонент не
меняет RectTransform-размеры, Canvas render mode, материалы или видимость UI.
Он не создаёт предметы в редакторе и не исправляет перекрытие материалами.

Родители перемещаемых корней должны иметь равномерный положительный масштаб.
При ошибочных ссылках, нулевом размере или перекошенном прямоугольнике в Inspector
появится сообщение, а положение объектов останется прежним. Не анимируйте
Transform целевых UI-корней одновременно с привязкой; анимируйте кости панели.

После настройки проверьте открытие, движение обеих панелей и закрытие:
3D-предметы должны совпадать с ячейками, закрытый квикбар — сохранять своё место.
