# Текстуры модели РУВИ

Рабочая модель находится в `Assets/Failsafe/Inventory/Ruvi/Models/Ruv-11_InventoryOpen1.fbx`,
а её экземпляр — в `Assets/Failsafe/Inventory/Ruvi/InventoryRobotPresentation (1).prefab`.

Для всех 32 деталей восстановлены участки материалов `RUVI_UNI_1`, `RUVI_UNI_2`
и `screen`. Они используют существующие текстуры из папки `Ruvi/Textures`.
Назначения восстановлены по `Inv-Boy_1.fbx`: индексы полигонов каждой детали
совпадают. Префаб назначает материалы в порядке подмешей, полученных при импорте.

Иерархия модели, идентификаторы объектов, привязка к костям и исходные записи
анимации сохранены. Продолжают использоваться четыре реакции контроллера
`RuviBody`, обратное закрытие, экран инвентаря на кости и отдельный экран мимики.
Внешнее движение по-прежнему управляется аниматором презентации, а корпус —
собственным аниматором.
